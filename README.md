# A template for Google Apps Script Project

## REQUIREMENTS

- [mise](https://mise.jdx.dev/)

## USAGE

### SETUP

- install Node.js and pnpm dependencies

  ```shell
  mise install
  ```

### COMMANDS FOR GAS

- login to clasp

  ```shell
  pnpm run login
  ```

- create new project

  ```shell
  pnpm run create
  ```

- clone project already exists

  ```shell
  pnpm run clone <SCRIPT_ID>
  ```

- push project

  ```shell
  pnpm run push
  ```

- pull project

  ```shell
  pnpm run pull
  ```

- invoke function

  ```shell
  pnpm run invoke <FUNCTION_NAME>
  ```
